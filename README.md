# Prism:Refactor

Prism:Refactor is an early-stage project exploring a new compatibility layer for running Windows games on macOS without relying on Wine.

## Goal

Build a translation layer that maps the Windows interfaces games depend on to macOS and Apple hardware, so Windows games can run natively on a Mac through Prism:Refactor.

## Project status

Planning has begun, but the translation layer is not implemented yet. No games are currently supported.

## Guiding principles

- Create a new compatibility layer rather than depending on Wine.
- Develop support incrementally and document compatibility clearly.
- Respect the licenses and intellectual property of games, operating systems, and related projects.

## Roadmap

- [ ] Research the Windows APIs and graphics interfaces needed by target games.
- [ ] Define the translation layer's architecture.
- [ ] Build a minimal prototype.
- [ ] Create a test plan and publish compatibility results.

## Contributing

Design discussions, research, and implementation contributions are welcome. Build and contribution instructions will be added as the project takes shape.
